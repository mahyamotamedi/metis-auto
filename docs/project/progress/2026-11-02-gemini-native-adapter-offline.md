## Gemini native adapter through the Metis wrapper, offline only (2026-11-02)

Plan stretch item 1, approved by the lead (Mahya) on 2026-11-02. Pipeline B, branch `gemini-adapter-offline`. **No live call, no new dependency**: `pyproject.toml`, the locks, and `constraints-min-age.txt` are unchanged. **Awaiting review.**
- **Adapter** `adapters/providers/gemini_native.py` ([ADR-XXXX (gemini-native-adapter)](../../adr/draft-gemini-native-adapter.md)): `ModelClient` on the standard library (`urllib.request`, `json`) behind an injectable `Transport`. One request per invoke. Usage, finish reason, and the nine error classes are normalised as in `openai_compat`; 402 maps to `auth` with `payment_required`, since no budget class exists. Verified (Metis docs, re-read 2026-11-02): base URL, path, header. **Not verified:** every JSON field name (no recorded Gemini response in the repo), and both token conventions. A cached count > 0 makes usage unknown (`PROMPT_COUNT_INCLUDES_CACHED = None`). Thinking inside or outside the candidates count is decided per response from the total; when undecidable, output and reasoning are unknown, never 0.
- **Thinking:** `[model_options] thinking_budget` (new `ModelRequestOptions` field, integer ≥ 0, allowed only for `google_genai` endpoints; left out of dumps while unset, so config hashes are unchanged). It is sent on every call; unset means the adapter refuses to call. Thinking tokens bill as output.
- **Wiring:** `wiring.live.build_live_client` routes enabled `google_genai` endpoints to the adapter through `adapters/providers/dispatch.py` (`ModelDispatchClient`). With none enabled (today) the stack is unchanged. The `gemini` endpoint stays `deferred`; the catalogue has no Gemini row (none existed); `endpoints-metis.toml` is unchanged.
- **Architecture tests** (`test_live_sdk_imports.py`): stdlib HTTP only in the adapter, plus the pre-existing HF token check in `wiring/db_ingest.py`, which is listed as an exception; no Gemini SDK or undeclared HTTP client anywhere; no eager import.
- **Live check, written, not run:** `scripts/live_gemini_check.py` (`wiring/gemini_check.py`; live half `wrapper_check.run`). One SYNTHETIC message, printed estimate first (input + output cap 64 + thinking budget), run cap 0.01 USD, ledger, required `--thinking-budget`. Needs [ADR-XXXX (gemini-live-calls)](../../adr/draft-gemini-live-calls.md) (amends ADR-0018 point 2; proposed), a raised dashboard limit, the enabling step, and per-run approval.
- Tests (fake transport only): `tests/unit/adapters/test_adapters_gemini_native.py`, `test_adapters_dispatch.py`, `tests/unit/settings/test_settings_gemini.py`, `tests/integration/test_live_wiring_gemini.py`, `test_gemini_check.py`.
- Baseline before the change: 3 failed, caused by the environment (git 2.23 has no `init -b`; `data/tokenizers/` not fetched). They are unchanged by this work.
