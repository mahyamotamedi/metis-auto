- **Design (ADR-0016 Part 1):** for each naive day *d*, the admitted keys have ≥ `min_count` eligible occurrences in ≥ `min_sessions` sessions on days *d − window_days … d − 1* (no look-ahead; `window_days` 1 to 180; the plan's 90, 3, 2 are passed by the caller). Key: `bot_id` + `bot_ins_h_exact` + `u_h_norm`. The stored answer is the mode of `a_h_norm`; `pq_answer_agrees` is agreement, not correctness. Hit rows zero both cost blocks. Evidence class *simulation*, `correctness_state` `unmeasured`.
- **Variants:** `first_turn` (headline, `cache.popular_question.first_turn`) and `all_turns` (upper bound, unsafe for follow-up questions).
- **Decided (owner, 2026-11-02):** "no logged history" is `n_prior_msgs == 1`. At an AI row, `n_prior_msgs` counts the request's own question (checked in `history_columns` on a synthetic session), so `== 0` would admit nothing. The EDA's H-8 figures use `turn == 0`.
- **Verified in code:** `u_h_norm` is `fingerprint(normalize_safe(text))` (`analysis/ingest.py`); `bot_ins_h_exact` exists but comes from a bot snapshot, so it never splits a bot's traffic. Eligibility funnel: the six EDA exact-cache steps in the EDA's order, then `key_known`, `llm_request`, `no_memory` (True and unknown out), `no_rag` (retrieval run or malformed out), `first_turn`.
- **Tests:** the 15 tests failed first against a stub and now pass. `pytest tests/unit/experiments tests/unit/analysis tests/architecture`: 124 passed; full `pytest -q`: 1215 passed, 22 skipped; ruff check and format clean.
- **Decided (owner, 2026-11-02), guard keys:** `key_version` is a constructor argument. `keys()` builds `"<key_version>|<body>"` with `cache_guard.versioned_key` ([ADR-0034](../../adr/0034-cache-guard-key-encoding-and-check-order.md)); the caller passes the guard's own version. Two tests added (17 in all), one with B's real `CacheGuard`: a key under another version is refused.
