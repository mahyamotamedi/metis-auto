- **Router off is byte-identical:** digests of every event and response over 8 SYNTHETIC requests under `fixed_model`, `rule_based`, `sticky` and `decision_router`, captured from the R3 code before any change (`tests/fixtures/synthetic/router_off_golden.json`), are reproduced exactly (also across hash seeds).

To be run natively by the owner.
- **Decisions here:** A-102 (run states count as dataset-derived by default), A-103 (low confidence ends the chain), A-104 (the router's own spend guard; a hosted error charges the estimate and stops hosted router calls), A-105 (confidence gate on the lowest reported confidence; none reported, no gate).
