## Context
The plan's routing step needs a cheaper model per request, but no quality label exists: the paid benchmark (P-1 to P-3) has not run, golden-v2 labels are provisional rule labels, and the logged model is what the bot's owner chose, not a verdict on quality. The plan's label-free version for Pipeline B is a **nearest-profile policy**: pick the cheapest model that requests with the nearest profiles already run on. Without labels, a saving-maximising choice of any parameter would always pick the most aggressive setting. The logs also limit what can be priced: on the tune split, 119,854 of 209,331 LLM rows (57.3%) ran on a model with no row in the price file, and the cached-token convention differs by logged model (five models report cached tokens outside the input count).

## Decision
1. **Policy** (owner brief). For a request, take the `k` nearest **fitting** profiles, never from the request's own session or duplicate family (`(bot_id, u_h_norm)`, as in `replay_scope`). Collect the models those neighbours ran on; keep the routing candidates (`sprint.toml [routing] candidates` plus `candidates_jev`) that the **injected** `eligible_models(row, catalogue, prices, rules)` allows; choose the cheapest on this request's tokens. Move only if strictly cheaper than the incumbent; never upward. Keep the incumbent, with a recorded reason, when the tokens are unknown, the incumbent has no price, the bot has fewer than `min_n` fitting rows (`sprint.toml [sufficiency]`), fewer than `k` neighbours remain, or no eligible candidate is cheaper. Recorded cost blocks and fees are never changed.
2. **Neighbours may come from any bot** (agent). Inside one bot every request ran the bot's single model, so same-bot neighbours can only return the incumbent.
3. **Profile and distance** (agent, within the brief's allowed list). Features known before the model is chosen: `n_prior_msgs`, `prior_chars`, `a_rag_n_chunks`, `a_rag_chunk_chars`, `u_att_n`, `u_n_chars` (`log1p`) and a one-hot `u_lang`. Excluded as answer-derived: `a_tool_n_calls`, `a_is_json`, `a_finish_reason`, output tokens, cost; excluded as a configuration snapshot: `bot_*` columns. Median fill, mean and standard deviation from the fitting rows only. Euclidean distance in float32; ties go to the lower training position.
4. **k and its criterion, declared before any run** (owner brief: small fixed grid, all of it reported, a conservative default, not the highest saving). Grid {5, 15, 50}. Criterion: *least aggressive*, the `k` with the lowest share of requests moved, ties to the smaller `k`.
5. **Validation** (agent). Session- and family-grouped nested cross-validation inside the tune split, 5 outer × 3 inner folds. A fold is a set of components (sessions joined by a shared duplicate family), so no fold shares a session or a family with another; every fit, scaling included, sees only rows outside the fold it scores. The default is the `k` most outer folds choose. The report period is not read.
6. **Pricing and units** (owner brief). The routed cost is `baselines_full.baseline_costs` on a copy with each row's model set to the routed model and the input already effective (cached tokens added back for the **logged** model), read as `todays_models`. Every baseline of a result is computed over the rows the router can price. The saving against a repriced baseline is that baseline's cost minus the routed cost (price-file units, `token_cost` only); against `as_logged` (recorded units) it is **not computed** (empty, never 0). The router's own effect is the `todays_models` figure.
7. **Labels** (owner brief). `label_source` is `None`; any other source is refused as "supervised use blocked" until benchmark labels with provenance exist and their sessions are disjoint from every fit. Every result carries "cost simulation; quality not proven".
8. **Eligibility: interim, superseded in part.** On 2026-11-02 no routing base existed, so R-B3 injected its own `eligibility_interim.py` (candidate, enabled, not retiring, priced, known window and output limit that fit, no attachment, no configured function), and every result says "interim eligibility, not the shared routing base". ADR-0045 promoted these rules to `analysis.routing_base.eligible_models`, with one change: an unknown attachment count now excludes the request. **Pending:** inject the shared function, delete the interim file and re-run.

## Alternatives considered
- **The `k` with the highest saving, or the largest `k`.** Without quality labels this rewards aggressiveness only. Rejected (owner brief).
- **A support threshold** (a model counts only if a share of the `k` neighbours ran it). A second free parameter with no label to fit it. Not used; `route_support` (the share that ran the chosen model) is reported instead (median 0.20 at `k` = 5, 0.04 at `k` = 50).
- **Same-bot neighbours only.** Can never move a request (point 2). Rejected.
- **Neighbours from a seeded subsample, or binned profiles,** to save time. The whole `rb3` run, nested CV included, took about 16 minutes on the full tune split, so no approximation was needed.
- **Logged model as a label** (supervised kNN or a classifier that predicts the logged model). Learns who chose a model, not whether a cheaper one is good enough. Rejected (owner brief).
- **Decide the move again inside each baseline** (that baseline's model is the incumbent, so every baseline's saving is the lever's own effect at that baseline's prices). Point 6 follows the brief instead. ADR-0046 (point 6, provisional) chose the per-baseline incumbent for R-C3, so the two routing results differ in meaning against `premium_gpt_5_5` and `best_single_cheap` (Consequences).
- **Price `as_logged` through implied recorded rates** (ADR-0038's pattern, which ADR-0046 point 5 uses for R-C3). Not done here: point 6 keeps recorded and price-file units apart and leaves `as_logged` not computed; the team should pick one rule for I-2.
- **scikit-learn's `NearestNeighbors`.** A new dependency and an ADR for a plain search that NumPy does. Not needed.

## Consequences
- **Results (tune split, `code_commit` 5a68fb6, 2026-11-02; cost simulation; quality not proven; interim eligibility):** every outer fold chose `k` = 5. At `k` = 5, 3,692 of 209,331 LLM requests move (1.76%) and the saving is **0.70% [0.54, 0.89]** of today's-model cost over the 88,971 rows the router can price (session-clustered interval). The grid points not chosen: `k` = 15 1.79%, `k` = 50 3.55%. Against `premium_gpt_5_5` the figure (97.4%) is almost all the premium price; against `best_single_cheap` it is −131% (one cheap model everywhere ignores every constraint and quality).
- **Reachability:** a nearest-profile policy can only choose a model that neighbours ran. The two cheapest candidates were logged on 9 (`mimo-v2.5`) and 3 (`gpt-5-nano`) tune-split LLM rows, so they are almost never chosen.
- **The routing decision rule cannot be passed** (acceptable rate within 10 points of the incumbent needs labels). The results stay out of any final cross-pipeline comparison until point 8 is switched over.
- **`compare` ranks the grid by saving** (`k` = 50 first), the ordering point 4 refuses; the declared default is in each result's `assumptions` and in the summary, not in a field `compare` reads (Q-B23, `docs/experiments/pipeline_b_interim_contracts_day3.md`).
- **Two meanings of "saving against a repriced baseline" exist:** the baseline minus the pipeline's routed cost (point 6 here), and the lever's own effect at each baseline's prices (ADR-0046 point 6 for R-C3; R-B2's before-minus-after is the same idea). R-B3 and R-C3 also differ on `as_logged` (not computed here; implied recorded rates in ADR-0046). A combined waterfall (I-2) needs one rule for both (Q-B21).
- **Routing after context:** `levers.combine` hands routing the frame context returned, whose `a_bill_inputTokens` is unchanged, so routing reprices pre-context tokens (Q-B20). The B-only dry run states its own assumption (`experiments/pipelines/b-only-dry-run/`).
- Overhead is not measured: `scripts/measure_lever_overhead.py` builds no B version (Q-B24).
- Guarding tests: `tests/unit/experiments/test_knn_router.py` (`test_labels_only_from_declared_source`, `test_quality_not_proven_in_assumptions_without_labels`, `test_small_n_insufficient_or_wide_interval`, `test_scaling_is_fitted_on_training_rows_only`, `test_no_self_neighbour_same_session_or_family_excluded`, `test_neighbours_may_come_from_other_bots`, `test_ties_are_broken_by_training_order`, `test_cold_start_keeps_the_incumbent`, `test_never_routes_upward`, `test_hard_constraints_come_from_the_injected_eligible_models`, `test_fee_and_recorded_blocks_unchanged`, `test_candidate_costs_match_baselines_full`) and `tests/unit/experiments/test_knn_router_run.py` (`test_session_grouped_nested_cv`, `test_folds_keep_sessions_and_families_together`, `test_criterion_is_least_aggressive_not_highest_saving`, `test_routed_cost_reprices_through_baselines_full`, `test_one_result_per_baseline_with_units_never_mixed`).
