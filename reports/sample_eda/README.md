# Sample EDA (outputs) — preliminary, sample-only

Figures and feature-only tables produced by `experiments/sample_eda/eda.ipynb`. They use hashed or opaque IDs and contain no raw content.

- This is an **exploratory** analysis of the 100-session sample, run to judge whether the project was worth doing. It is **not** the finalised EDA.
- Every number is a provisional signal, to be re-verified on the full dataset.
- `experiments/sample_eda/eda_helpers.py` is deliberately simplified and **not reliable**. Do not import, copy, or build on it from any other code. Read it only as a record of what was tried.
- The full-dataset EDA will live in a separate home (Stage 2 proposal).
